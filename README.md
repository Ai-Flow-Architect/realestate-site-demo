# 不動産会社のホームページ（デモ）

架空の不動産会社「あおい不動産」のコーポレートサイトのデモです。会社名・住所・電話番号・免許番号はすべて架空です。

- 映像が切り替わるトップ・実際の写真・スクロールの動きを備えた、シンプルで落ち着いたデザイン
- 事業内容（売買仲介・賃貸仲介・賃貸管理・リノベーション・事業用物件・住まいのご相談）／数字／ご相談の流れ／よくある質問／会社概要／お知らせ／お問い合わせ
- スマホ対応・端末がダークモードでも白地で表示
- 静的ファイルだけで動きます（サーバー・データベース不要）

写真と映像は CC0・Public Domain Mark・CC BY・Mixkit Free License の素材です。出典はページのフッターに載せています。
